# EasyBook

**EasyBook** — бесплатная self-hosted система онлайн-записи, работающая внутри Telegram Mini App.

Проект подходит для салонов красоты, барбершопов, частных мастеров, студий и других небольших бизнесов, которым нужна собственная система записи клиентов без сторонних сервисов и ежемесячных подписок.

> **Одна установка EasyBook = один бизнес.**

Клиенты записываются через Telegram, а владелец, администраторы и исполнители управляют услугами, расписанием и записями через тот же Mini App.

## ✨ Возможности

### 👤 Для клиентов

- выбор одной или нескольких услуг;
- выбор подходящего исполнителя;
- просмотр доступных дат и времени;
- автоматический учёт длительности выбранных услуг;
- временное удержание слота во время оформления;
- просмотр своих записей;
- отмена записи;
- перенос записи;
- уведомления через Telegram;
- авторизация через Telegram без отдельных аккаунтов и паролей.

### 🛠 Для владельца и администратора

- просмотр всех записей;
- ручное или автоматическое подтверждение;
- создание записи вручную;
- перенос и отмена записей;
- отметка выполненных записей;
- управление исполнителями;
- управление услугами;
- назначение услуг конкретным исполнителям;
- индивидуальная стоимость и длительность услуги для каждого исполнителя;
- настройка рабочего графика;
- выходные и особые рабочие дни;
- блокировка отдельных временных интервалов;
- настройка правил отмены и переноса записей.

### 👥 Для исполнителей

Каждому исполнителю можно привязать его Telegram-аккаунт.

Исполнитель получает собственный интерфейс EasyBook, где может просматривать свои записи и рабочее расписание.

## 📅 Как работает запись

Стандартный сценарий для клиента:

**Услуги → Исполнитель → Дата → Время → Подтверждение**

EasyBook автоматически учитывает:

- выбранные услуги;
- исполнителей, которые могут их выполнить;
- длительность каждой услуги;
- рабочий график исполнителя;
- выходные и исключения;
- заблокированные интервалы;
- существующие записи;
- временно удерживаемые слоты.

Если клиент выбирает несколько услуг, EasyBook рассчитывает их общую продолжительность и показывает только подходящие свободные интервалы.

Например, если услуги занимают в сумме **2 часа 30 минут**, клиент увидит только те варианты, где у выбранного исполнителя действительно свободны непрерывные 2,5 часа.

## 👥 Несколько исполнителей

EasyBook поддерживает работу с несколькими исполнителями.

У каждого могут быть собственные:

- услуги;
- цены;
- длительность услуг;
- рабочие дни;
- рабочие часы;
- выходные;
- записи.

Например:

```text
Артём
├── Мужская стрижка — 60 минут
└── Маникюр — 90 минут

Анна
├── Маникюр — 60 минут
└── Брови — 45 минут
```

Занятость одного исполнителя не блокирует запись к другому.

Если клиент выбирает несколько услуг, EasyBook предложит только тех исполнителей, которые могут выполнить весь выбранный набор.

---

## ⏱ Расписание

Для каждого исполнителя можно настроить собственную рабочую неделю.

Например:

```text
Понедельник    09:00 — 18:00
Вторник        10:00 — 20:00
Среда          Выходной
Четверг        09:00 — 18:00
Пятница        09:00 — 18:00
```

Кроме стандартного расписания можно:

- закрыть определённый день;
- открыть обычно нерабочий день;
- установить особые часы на конкретную дату;
- добавить перерыв;
- заблокировать отдельный временной интервал.

Это позволяет менять расписание без изменения основной рабочей недели.

---

## 🔒 Временное удержание слотов

EasyBook защищает от ситуации, когда два клиента одновременно пытаются записаться на одно время.

Во время оформления записи слот временно резервируется.

По умолчанию время удержания составляет:

```text
15 минут
```

Если запись не будет завершена или подтверждена в установленный срок, временная бронь автоматически освобождается.

---

## ✅ Подтверждение записей

EasyBook поддерживает два режима работы.

### Автоматический

После оформления запись автоматически становится подтверждённой.

### Ручной

После оформления запись ожидает подтверждения администратора.

Администратор может проверить заявку и подтвердить её самостоятельно.

Режим выбирается в настройках бизнеса.

## 🎨 Telegram Mini App

Основной интерфейс EasyBook работает непосредственно внутри Telegram.

Отдельный клиентский сайт не требуется.

Интерфейс поддерживает:

- светлую тему;
- тёмную тему;
- автоматическое определение темы Telegram;
- ручное переключение темы;
- мобильный интерфейс;
- адаптацию под Telegram WebApp.

Авторизация выполняется через Telegram Mini App `initData`.

Клиентам не требуется создавать отдельные аккаунты.

## 🚀 Установка

### Требования

Для запуска понадобятся:

- Python;
- Telegram Bot Token;
- Telegram ID владельца;
- сервер/VDS или компьютер для разработки;
- HTTPS-домен для production.

Клонируйте репозиторий:

```bash
git clone https://github.com/buzyak/EasyBook.git
cd EasyBook
```

Создайте `.env` из примера.

### Windows

```powershell
Copy-Item .env.example .env
```

### Linux

```bash
cp .env.example .env
```

Откройте `.env` и заполните основные параметры:

```env
BOT_TOKEN=
OWNER_TELEGRAM_ID=

PUBLIC_BASE_URL=https://example.com
SECRET_KEY=change-me

DATABASE_URL=sqlite+aiosqlite:///./data/easybook.db

HOLD_MINUTES=15
TIMEZONE=Europe/Moscow
DEV_MODE=false
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите EasyBook:

```bash
python run.py
```

По умолчанию приложение будет доступно по адресу:

```text
http://127.0.0.1:8000
```

## 🤖 Telegram Bot

Создайте нового бота через **@BotFather** и получите его токен.

Добавьте токен в `.env`:

```env
BOT_TOKEN=YOUR_BOT_TOKEN
```

Также укажите Telegram ID владельца:

```env
OWNER_TELEGRAM_ID=123456789
```

После запуска отправьте боту:

```text
/start
```

Бот предоставит кнопку для открытия EasyBook Mini App.

## 🧪 Локальное тестирование

Для нормальной работы Telegram Mini App требуется HTTPS.

При локальной разработке можно использовать Cloudflare Tunnel.

Запустите EasyBook:

```bash
python run.py
```

В другом терминале:

```bash
cloudflared tunnel --url http://127.0.0.1:8000
```

Вы получите временный адрес вида:

```text
https://example.trycloudflare.com
```

Укажите его в `.env`:

```env
PUBLIC_BASE_URL=https://example.trycloudflare.com
```

После изменения `.env` перезапустите EasyBook.

## 🐳 Docker

EasyBook также можно запустить через Docker Compose.

Клонируйте проект:

```bash
git clone https://github.com/buzyak/EasyBook.git
cd EasyBook
```

Создайте конфигурацию:

```bash
cp .env.example .env
```

Заполните `.env`, затем выполните:

```bash
docker compose up -d --build
```

Для production рекомендуется использовать собственный домен с HTTPS и reverse proxy.

## ⚙️ Первый запуск

После установки:

1. Создайте Telegram-бота.
2. Добавьте `BOT_TOKEN` в `.env`.
3. Укажите свой Telegram ID в `OWNER_TELEGRAM_ID`.
4. Укажите публичный HTTPS-адрес в `PUBLIC_BASE_URL`.
5. Запустите EasyBook.
6. Отправьте боту `/start`.
7. Откройте Mini App.
8. Настройте бизнес.
9. Добавьте услуги.
10. Добавьте исполнителей.
11. Назначьте услуги исполнителям.
12. Настройте расписание.

После этого EasyBook готов принимать записи.

## 💾 База данных

По умолчанию EasyBook использует **SQLite**.

```env
DATABASE_URL=sqlite+aiosqlite:///./data/easybook.db
```

Такой вариант позволяет развернуть небольшую установку без отдельного сервера базы данных.

Для работы с БД используется SQLAlchemy.

Файл базы данных находится в `data/` и исключён из Git.

---

## 🔐 Безопасность

Секретные данные хранятся в `.env`.

Никогда не публикуйте:

```text
.env
BOT_TOKEN
SECRET_KEY
базу данных EasyBook
```

В репозитории должен находиться только `.env.example` без реальных секретных данных.

---

## 🌍 Timezone

Часовой пояс задаётся через `.env`:

```env
TIMEZONE=Europe/Moscow
```

По умолчанию EasyBook использует московское время.

При необходимости значение можно изменить под регион бизнеса.
