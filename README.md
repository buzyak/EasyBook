# EasyBook

**EasyBook** — self-hosted система онлайн-записи внутри Telegram Mini App.

Одна установка EasyBook = один бизнес. Никаких отдельных кабинетов на сторонних сайтах: клиент, владелец и исполнители работают через Telegram.

## Что уже работает в v0.2

### Для клиента

- выбор одной или нескольких услуг;
- затем выбор исполнителя, который умеет выполнить весь набор;
- выбор даты и реально свободного времени;
- учёт полной длительности выбранных услуг;
- телефон для связи;
- temporary hold на заданное количество минут;
- ручное или автоматическое подтверждение;
- просмотр своих записей;
- отмена и перенос в рамках правил бизнеса.

### Для владельца / администратора

- список и статусы записей;
- подтверждение и отмена;
- завершение записи;
- перенос записи;
- ручное создание записи;
- управление исполнителями;
- управление услугами;
- назначение услуг исполнителям;
- отдельная длительность/цена услуги для каждого исполнителя;
- недельный график каждого исполнителя;
- закрытие целого дня;
- особый график на конкретную дату;
- закрытие произвольного интервала, например обеда;
- ручное/автоматическое подтверждение;
- настройка шага записи, горизонта записи, отмен и переносов.

### Для исполнителя

Исполнителю можно привязать Telegram ID. После этого он получает собственный Mini App-кабинет с рабочими записями и своим графиком. Право изменять график включается владельцем отдельно.

## Быстрый локальный запуск на Windows

Создай `.env` из примера:

```powershell
Copy-Item .env.example .env
```

Заполни минимум:

```env
BOT_TOKEN=123456:telegram-token
OWNER_TELEGRAM_ID=123456789
PUBLIC_BASE_URL=https://your-public-https-url.example
SECRET_KEY=replace-with-long-random-string
DATABASE_URL=sqlite+aiosqlite:///./data/easybook.db
HOLD_MINUTES=15
TIMEZONE=Europe/Moscow
DEV_MODE=false
```

Установи зависимости и запусти:

```powershell
pip install -r requirements.txt
python run.py
```

Локально backend будет доступен на `http://127.0.0.1:8000`, но Telegram Mini App требует HTTPS.

Для локального тестирования удобно использовать Cloudflare Tunnel:

```powershell
cloudflared tunnel --url http://127.0.0.1:8000
```

Полученный `https://....trycloudflare.com` укажи в `PUBLIC_BASE_URL` и перезапусти EasyBook.

## Запуск на VDS через Docker

```bash
git clone <your-easybook-repository>
cd EasyBook
cp .env.example .env
# заполнить .env
docker compose up -d --build
```

Для production нужен домен с HTTPS, который проксирует запросы на EasyBook `:8000`.

## Первый запуск

1. Создай Telegram-бота через BotFather.
2. Укажи токен и свой Telegram ID в `.env`.
3. Запусти EasyBook.
4. Отправь боту `/start`.
5. Открой Mini App.
6. Введи название бизнеса — часовой пояс по умолчанию `Europe/Moscow`.
7. Добавь исполнителей.
8. Добавь услуги и назначь исполнителей.
9. Настрой рабочий график.

После этого клиент может открыть этого же бота и записываться.

## Архитектура

```text
Telegram
   │
   ├── Bot — вход и уведомления
   │
   └── Mini App
          │
          ▼
      FastAPI API
          │
          ▼
       Database
```

```text
EasyBook/
├── backend/       # API, авторизация, расписание и бронирования
├── bot/           # Telegram bot
├── miniapp/       # интерфейс Mini App
├── data/          # SQLite data volume
├── Dockerfile
├── docker-compose.yml
├── run.py
└── .env.example
```

## База данных

По умолчанию используется SQLite — это удобно для одной небольшой/средней self-hosted установки. Архитектура на SQLAlchemy оставляет возможность перейти на PostgreSQL позднее.
