# Changelog

## 0.2.1 — Beauty UI Refresh

- новый нежный beauty-интерфейс с olive/sage акцентом
- светлая и тёмная темы, тема автоматически берётся из Telegram
- боковая кнопка ручного переключения темы на текущую сессию
- исправлены слипшиеся подписи и мобильные отступы
- рабочая неделя полностью переработана
- время в интерфейсе и графике отображается в 24-часовом формате
- `Europe/Moscow` больше не торчит на главном экране как техническое значение
- переработан перенос записи клиента: отдельный экран подтверждения, состояние «Переносим…», явный успех и видимая ошибка
- availability при переносе корректно исключает текущую запись из проверки конфликтов

## 0.2.0

- Полноценная авторизация Telegram Mini App через `initData`.
- Роли owner / admin / performer / client.
- Дефолтный часовой пояс `Europe/Moscow`.
- Клиентский flow: услуги → исполнитель → дата → время → телефон → запись.
- Несколько услуг в одной записи.
- Индивидуальная длительность и цена услуги у исполнителя.
- 15-минутный temporary hold и ручное/автоматическое подтверждение.
- Автоматическое освобождение истёкших temporary hold.
- Панель владельца: записи, исполнители, услуги, настройки.
- Личный кабинет исполнителя.
- Недельный график, особые дни и ручная блокировка интервалов.
- Ручное создание записи администратором.
- Отмена и перенос клиентом по правилам бизнеса.
- Перенос/отмена/завершение записи администратором.
- Telegram-уведомления о новых записях и изменении статуса.
- Проверка конфликтов и длительности непрерывного слота.
- Подготовка к дальнейшим модулям: history, blacklist, waiting list, broadcasts.
